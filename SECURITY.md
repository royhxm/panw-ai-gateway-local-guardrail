# Security

This is a community integration with known classifier and deployment limitations.
Read [the limitations](docs/limitations.md) before using it to enforce policy.

Never include real tokens, private IPs, model/provider credentials, production
request bodies, PII, database files or private screenshots in public reports.
Use a minimal synthetic reproducer and the affected project/gateway versions.

For a sensitive vulnerability, use GitHub's private vulnerability reporting if
available for this repository. Do not post an exploit containing production data
in a public issue. No paid support or security SLA is provided.

The only initial release is 0.1.0. There is no commitment to maintain older
versions indefinitely. Review changelogs and dependency advisories before deployment.
